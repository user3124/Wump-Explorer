# План интеграции SonarCloud

Для автоматической проверки качества кода и поиска багов в нашем проекте нужно настроить облачный анализатор SonarCloud.

## Первичные шаги для интеграции

1. **Регистрация и создание проекта**
    * Создать аккаунт на сайте SonarCloud через авторизацию с помощью нашего GitHub.
    * Импортировать наш репозиторий в панель управления SonarCloud.

2. **Настройка прав**
    * Предоставить сервису доступ к чтению кода в нашей ветке.

3. **Локальная настройка проекта**
   * Поскольку использование систем сборки запрещено требованиями работы, анализ будет выполняться через консольный инструмент SonarScanner CLI.
   * Скачать архив SonarScanner CLI для используемой операционной системы и добавить путь к нему в системную переменную PATH.
   * В корневой директории проекта создать конфигурационный текстовый файл `sonar-project.properties`.
   * Внести в него базовые настройки:
     ```properties
     sonar.organization=название_организации
     sonar.projectKey=ключ_проекта
     sonar.projectName=Wump Explorer
     sonar.projectVersion=1.0
     sonar.sources=src
     sonar.language=kotlin
     sonar.sourceEncoding=UTF-8
     ```

4. **Запуск сканирования и отправка результатов**
   * Открыть терминал Git Bash в корневой папке проекта.
   * Выполнить команду запуска анализа, передав сгенерированный в личном кабинете токен безопасности:
     ```bash
     sonar-scanner -Dsonar.token=ваш_токен_безопасности
     ```
   * Дождаться окончания процесса, после чего утилита выведет в консоль прямую ссылку на готовый отчет в облаке SonarCloud.
