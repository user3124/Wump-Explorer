# Анализ SOLID

Пока провели первичный осмотр кода. Нашли явное нарушение первого принципа.

## Нарушение SRP (Принцип единственной ответственности)
* Класс `CliManager` в файле `CliManager.kt`.
* Этот класс делает сразу две вещи. Он и парсит входящие аргументы через библиотеку, и сам же содержит функцию `showHelpAndExit`, которая выводит текст справки в консоль через `println`.
* **Как исправить.** По-хорошему, вывод текста надо забрать у парсера и отдать какому-нибудь другому объекту, который умеет просто печатать логи.
